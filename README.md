# ⚔ RPG 冒險 ⚔

一個純前端的網頁角色扮演遊戲 —— 免安裝、免後端，打開瀏覽器就能玩。

從一隻野生史萊姆開始，一路轉職、抽果實、養寵物、打深淵、轉生飛升，
體驗數值不斷膨脹的放置型 RPG 樂趣。

---

## 🎮 怎麼玩

**直接開啟 `index.html` 即可遊玩**（需要瀏覽器支援 ES Module，建議用 Chrome / Edge / Firefox 最新版）。

或部署到任何靜態網站託管（GitHub Pages / Netlify / Vercel 皆可）。

> ⚠️ 雲端存檔功能需要 Firebase 設定（見下方「雲端存檔」章節）。

---

## ✨ 遊戲特色

- **12 種職業**，每個職業 4 階技能解鎖，可自由轉職並繼承等級
- **10+ 種惡魔果實**，4 階技能、元素相剋、專屬特效
- **10+ 種寵物**，自動參戰、專屬技能與被動
- **隨機裝備系統**：6 種稀有度、隨機詞綴、3 合 1 合成、附魔
- **天賦樹 + 突破里程碑**：點滿天賦後進入突破，解鎖質變加成
- **雙層 Prestige**：轉生 → 飛升，永久加成層層疊加
- **無盡深淵 + 5 個副本**：每 10 層 BOSS，越深越強
- **公會系統**：3 個公會、每日任務、公會技能樹、世界王
- **8 種賭場小遊戲**：拉霸、骰子、輪盤、21 點、賽馬……應有盡有
- **本地 + 雲端雙存檔**：LZ-String 壓縮分享碼，跨裝置接續進度

---

## 💾 存檔說明

### 本地存檔
自動儲存於瀏覽器 `localStorage`（key：`rpg_save_v6`）。

### 雲端存檔（Firebase）
登入後每 30 秒自動上傳至 Firebase Realtime Database，
可在不同裝置接續遊玩。

> 🔧 使用前請在 `index.html` 中填入你自己的 Firebase 設定：
> ```js
> const firebaseConfig = {
>   apiKey: "...",
>   authDomain: "...",
>   databaseURL: "...",
>   // ...
> };
> ```

### 分享碼備份
在「系統 → 雲端存檔」可產生 `RPG2:` 前綴的壓縮分享碼，
貼到另一台裝置即可匯入進度。

### 重開新檔
打開瀏覽器開發者工具（F12）→ Console，執行：
```js
localStorage.removeItem('rpg_save_v6');
location.reload();
